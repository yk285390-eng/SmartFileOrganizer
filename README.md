Smart File Organizer

A simple Python-based file organizer designed for Termux and Android.

Features

- Organize files by file type.
- Preview file movements before making changes.
- Avoid overwriting existing files.
- Safely handle duplicate filenames.
- Undo the last organization operation.
- Generate text reports.
- Beginner-friendly terminal interface.

Supported Categories

- Images
- Documents
- PDFs
- Videos
- Audio
- Archives
- Other files

Requirements

- Android phone
- Termux
- Python 3

Installation

git clone https://github.com/yk285390-eng/SmartFileOrganizer.git
cd SmartFileOrganizer
python main.py

Run Tests

python -m unittest -v

Safety

- Preview changes before organizing.
- No automatic file deletion.
- Existing files are protected from overwriting.
- Test with sample folders before using important files.
